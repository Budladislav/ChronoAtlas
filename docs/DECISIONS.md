# Архитектурные решения

## ADR-001: статический local-first frontend

ChronoAtlas работает без backend. IndexedDB через Dexie является источником пользовательских данных; `localStorage` хранит только безопасное состояние области просмотра.

## ADR-002: HashRouter и относительный base path

Маршруты используют hash-навигацию, а Vite собирает ресурсы с относительным `base`. Это позволяет одному артефакту работать локально и в GitHub Project Pages без серверных rewrite-правил.

## ADR-003: собственная временная шкала

Шкала реализуется небольшими React/CSS-компонентами и чистыми доменными функциями. Это сохраняет семантику неточных дат и не добавляет Gantt-зависимость.

## ADR-004: единый источник версии

Авторитетная версия находится в `package.json`, внедряется Vite как `__APP_VERSION__` и используется интерфейсом, changelog и backup.

## ADR-005: миграции и восстановление

Первая схема IndexedDB имеет версию 1. Backup имеет явный формат и версию схемы. Восстановление сначала валидирует весь документ, затем заменяет данные одной транзакцией.
