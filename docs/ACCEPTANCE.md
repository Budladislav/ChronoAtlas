# Приёмка MVP 0.1.0

Дата проверки: 16 августа 2026 года.

## Автоматизированные проверки

- `npm run check`: ESLint, strict TypeScript, 16 unit/component тестов и production build — пройдено.
- `npm run e2e`: 4 Playwright-сценария — пройдено.
- PWA production build: service worker и manifest сгенерированы, offline reopen пройден в Chromium.
- Synthetic fixture: упаковка 500 записей в дорожки укладывается в установленный тестовый лимит.
- Privacy smoke: приложение не содержит удалённых шрифтов, аналитики, backend или внешних runtime API.

## Визуальная матрица

Проверены реальные production-экраны:

- карта: 1366×768, 1440×900 и 1920×1080;
- «Течение»: 1440×900;
- настройки в тёмной теме: 1440×900;
- карта и панель выбранной записи: 390×844 в тёмной теме;
- отсутствие overflow страницы проверяется автоматически на desktop и 390 px.

## Приёмочные сценарии

AC-01–AC-15 покрыты комбинацией domain/component тестов и Playwright: onboarding, дата до рождения, продолжающийся период, приблизительный год, дорожки пересечений, сохраняемая фильтрация, «Течение», IndexedDB persistence, offline reopen, export/restore, невалидный импорт без изменения данных, версия/changelog, сохранность схемы, отсутствие внешних runtime-интеграций и единая команда качества.
