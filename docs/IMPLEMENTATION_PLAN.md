# План реализации MVP

1. Основа: React/Vite/TypeScript, качество, дизайн-система, маршруты и документация.
2. Домен: DateSpec, календарные вычисления, viewport, дорожки, Dexie и backup.
3. Оболочка: onboarding, профиль, темы, навигация и настройки.
4. Течение: календарные карточки и фактическая продолжительность жизни.
5. Карта: ось, периоды, моменты, выбор, zoom/pan и fit-команды.
6. Редактирование: единая форма записи, категории, удаление и keyboard UX.
7. Надёжность: импорт/экспорт, PWA, обновления, changelog и GitHub Pages.
8. Приёмка: unit/component/E2E, четыре viewport, обе темы, offline и synthetic 500.

Статус релиза `0.1.0`: все этапы MVP реализованы. Проверки и соответствие приёмочным сценариям зафиксированы в `docs/ACCEPTANCE.md`.
