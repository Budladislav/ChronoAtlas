# ChronoAtlas

«Личный атлас времени» — приватная desktop-first PWA для отображения периодов и событий жизни на общей временной шкале. Приложение хранит данные только в IndexedDB текущего браузера, не требует аккаунта и не отправляет личные записи на сервер.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run check
npx playwright install chromium
npm run e2e
```

Production-сборка появляется в `dist/`. GitHub Actions проверяет основную ветку и публикует статический артефакт в GitHub Pages.

## Возможности 0.1.0

- карта жизни с точными, месячными, годовыми и приблизительными датами;
- завершённые и продолжающиеся периоды, моменты и дорожки пересечений;
- пользовательские категории, порядок, цвета и сохраняемая видимость;
- течение дня, недели, месяца, года и фактическая продолжительность жизни;
- темы, клавиатурное управление, responsive-режим и PWA offline shell;
- транзакционный импорт/экспорт JSON и встроенная история изменений.

## Данные и резервные копии

Смена браузера, устройства, адреса публикации или очистка данных сайта может сделать локальную базу недоступной. Используйте экспорт JSON в настройках и храните файл безопасно: он не зашифрован и содержит личные данные.
